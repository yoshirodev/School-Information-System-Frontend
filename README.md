# EdSync: School Information System — Medroso-Mendoza National High School

A web-based School Information System developed for **Medroso-Mendoza National High School**. This application provides role-based access and management tools for students, teachers, and registrar staff.

## Project Status

* **Current Phase:** Frontend Prototype

* **Database Integration:** Not yet implemented (currently operating with client-side mock data and state management)

## Tech Stack

* **Framework:** React

* **Build Tool:** Vite

* **Styling:** Tailwind CSS

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your local machine before running the project.

### Running Locally

1. Navigate to the frontend directory:

   ```
   cd sis-frontend
   
   ```

2. Install the required dependencies:

   ```
   npm install
   
   ```

3. Start the local development server:

   ```
   npm run dev
   
   ```

4. Open the local URL provided in your terminal (typically `http://localhost:5173`) to view the application.
